# SOC Home Lab — Threat Detection & Incident Response

## Overview

Laboratorio práctico de ciberseguridad enfocado en la
monitorización de eventos, detección de amenazas y respuesta
a incidentes.

## Objectives

- Monitorizar eventos de Windows y Linux.
- Analizar alertas de seguridad.
- Investigar actividades sospechosas.
- Documentar incidentes.
- Relacionar detecciones con MITRE ATT&CK.

## Tools

- Wazuh
- Windows
- Linux
- Python
- MITRE ATT&CK
